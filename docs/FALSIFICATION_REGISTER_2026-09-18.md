# Component falsification register — 2026-09-18

Every residual component must now carry explicit observations that could downweight or eliminate it.

The register covers six evidence families: authoritative re-search, Ocean Infinity overlap, independent drift forcing, end-of-flight compatibility, SATCOM/trajectory exclusion, and physical sonar confirmation elsewhere.

This is deliberately asymmetric: weak contextual evidence cannot rescue a component that fails direct/authoritative physical constraints.

Physical confirmation remains the terminal criterion. A model peak, sonar anomaly, or robust component is not a wreckage discovery. Location ranking ends only after a target is physically confirmed through appropriate imagery/recovery evidence.

The script creates the falsification register only after real component IDs exist; otherwise it fails closed.
